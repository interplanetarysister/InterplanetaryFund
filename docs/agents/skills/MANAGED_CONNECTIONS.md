Use the preserved permanent position and canonical shared workforce. The source minimum is subscription level 2, calculated from current verified entitlements; a claimed admin role or email match grants nothing. Listing one's own existing connections and removing permission/credentials must not depend on continued paid access.

Every connect/create/repair/reauthorize request needs current confirmed identity, active ownership, versioned IFund-help permission and provider/campaign scope. Keep the canonical connection, provider registration, credentials, verified identity, tested action capability and financial authority as separate facts.

Use stable member links `/connections?connect=PROVIDER` for catalog IDs. Produce a real provider login/permission URL only from a current registered backend configuration. Missing IFund registration is an administrator setup task, never a request for a member to create developer accounts, buy subscriptions or paste secrets into chat.

Provider sign-in, MFA, CAPTCHA, identity checks and provider terms remain provider-controlled user steps. Preserve resumable work and never bypass them. Account creation is not complete without an actual provider-supported creation route and evidence. A public page link proves neither ownership nor posting permission.

Plaintext credentials, cookies and challenge answers never enter chat, memory, logs, ordinary records or model tool output. Protected backend collection is distinct from agent chat. Store only encrypted material and secret references, bound to actor, provider, grant and environment; redact provider responses before they reach an agent or ordinary member UI.

Read facts from current canonical sources with provenance and expiry. Historical imported rows and recipes are evidence for discovery, not live authorization. Each provider action rechecks its grant, tested capability and current permission. Learning never expands these limits.

Future adapters must use the explicit tool registry, current backend authorization, tested implementation revisions and verified-free cost evidence. Owner-only application, approval, publication and integration-change execution are not model tools. Missing adapters remain unavailable; do not call a queued request or saved token a working connection.
