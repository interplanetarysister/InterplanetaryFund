## Mandatory release blockers

- `apps/web/ci/verify-route-readiness.mjs` is **fail closed**: 80 tracked routes, **3 source_ready**, **77 not_verified**, 0 not_implemented. These rows need individual source, test and (where protected) backend/RLS evidence, not generic page-render claims. Do not bulk-approve based on a smoke test.
- The unsigned / absent verified member and administrator positive browser journeys: signup, account terms, draft save, media, social publishing, notifications, external consent/revocation, finances and admin actions require actual identity-backed tests.
- AI image routes require verified free-tier Cloudflare `AI` binding, quota setup, an authorized model call, valid JPEG and R2 storage roundtrip; no Pages AI binding is currently configured. Do not label source UI as a live model or trigger unapproved paid inference.
- Preview uses production Supabase and its `/api/paypal/sandbox/status` reports sandbox not ready. Isolate side effects and prove sandbox provider-backed capture/ledger before claiming preview payment acceptance.
- Draft Connections PR #286 source diverges, OAuth provider client registrations and permissions are not verified. Approval gates must remain fail closed.
- Public production and preview release require **separate** immutable artifact checks, signed-in browser QA, mobile checks, provider/ledger evidence, and a validated rollback target. A 465/465 frontend suite, 361/361 backend suite, or 80/80 guest browser smoke does not replace these.
- Do not weaken the mandatory acceptance manifest or Git auto-deploy controls solely to ship a visually successful bundle.

## Release decision

**HOLD: preview and production deployment not authorized by acceptance.** Owner's conditional instruction was to preview and then promote **only once independently verified issue-free**. With the above direct runtime defects and incomplete validation, publishing now would violate that condition and could expose live users to an unverified payment/member build. Continue source implementation, RLS/browser/provider acceptance and consolidate into **one** reviewed build and preview; promote the exact tested artifact to production only when all gates pass.
