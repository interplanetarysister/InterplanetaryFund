## Rules for additional image sourcing

- Inspect the actual file page and license, not search previews; use CC0/public domain when possible.
- For Creative Commons requiring attribution or share-alike, implement a visible credit mechanism *before* assigning.
- Never imply that the photograph shows a real fundraiser or recipient in a fictional campaign.
- Prefer optimized own R2 copies for long-term availability, but do not duplicate image bytes or pay for new services.
- Only update fictional sandbox records whose image field is blank, and never replace real organizer media.
- Verify image HTTP, browser render/CSP, responsive crop and public campaign association. Audit the source URL and author even when credit is not legally required.
- The pilot uses a direct Wikimedia URL and does not establish durable local R2 storage or complete visual acceptance.
