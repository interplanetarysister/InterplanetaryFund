## Purpose
This directory contains the canonical, portable knowledge base for the Interplanetary Fund Agent. It is designed to survive across runtimes — Base44, GitHub, future AI development environments — without losing institutional knowledge.

## Core Principle
Base44 is where the agent currently operates. It is not where the agent's institutional identity ends.
